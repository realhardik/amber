# Amber Documentation

The documentation for Amber has been consolidated directly into the respective package documentation to keep them fully self-contained and published with their npm packages:

- **[`amber-scroll` Documentation & API Reference](../packages/amber/README.md)**: Setup, HTML/CSS layout, configuration options, edge snapping, GPU parallax, section pinning, infinite loops, and React/Next.js/Vue integration.
- **[`amber-motion` Documentation & API Reference](../packages/motion/README.md)**: Zero-dependency CSS animation engine, timelines, optional `amber-motion/svg` morphing/stroke drawing, and direct scroll synchronization (`bindScroll`).
